# Synork Home — Home Assistant Add-on Repository

This is the official Home Assistant add-on repository for **Synork Home** — the
smart-home hub component of the [Synork](https://synork.dev) platform.

## Add this repository to Home Assistant

1. In Home Assistant, go to **Settings → Add-ons → Add-on Store**.
2. Click the **⋮** menu in the top right → **Repositories**.
3. Paste the URL of this repository:
   ```
   https://github.com/synork/synork-home-addon
   ```
4. Click **Add**, then close the dialog.
5. The **Synork Home** add-on will appear in your store. Install it.

Or use the one-click button:

[![Open your Home Assistant instance and show the add add-on repository dialog with this repository URL pre-filled.](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Fsynork%2Fsynork-home-addon)
